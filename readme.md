# 🌾 FarmBridge — Comparative Analysis & Transaction Simulation

**Author:** [Mohammad Armaan](https://mohammadarmaan.co.in)  
**Department:** Computer Science, Don Bosco Institute of Technology, Bengaluru  
**Keywords:** Blockchain, Smart Contracts, AI, Ethereum, IPFS, Disaster Relief, Simulation  

---

## 📘 Overview

This repository presents the **comparative analysis and transaction simulation** for **FarmBridge**, a blockchain and AI-driven decentralized platform designed for transparent agricultural relief distribution.  

The project compares **FarmBridge** with other blockchain-based humanitarian platforms through advanced natural language processing (NLP), keyword analysis, and semantic similarity scoring. It further simulates blockchain transaction parameters such as **throughput**, **latency**, and **gas cost** to assess scalability and efficiency.

---

## 🧮 Key Features

- **Comparative Analysis:** Evaluates FarmBridge against benchmark systems using semantic and TF-IDF-based keyword extraction.  
- **Multi-Metric Evaluation:** Measures six performance indicators:  
  - Accessibility  
  - Risk Resilience  
  - RBAC Quality  
  - User Experience  
  - Transaction Cost  
  - Transaction Time  
- **Semantic Scoring:** Uses transformer-based embeddings for precise semantic similarity evaluation.  
- **Visualization Suite:** Generates high-quality comparative charts — grouped bar, heatmap, radar, line, and stacked bar formats.  
- **Transaction Simulation:** Models transaction scalability and latency under increasing load using Ethereum Sepolia testnet data.

---

## 🧠 Methodology

1. **Text Extraction:** Extracts text from research PDFs using NLP-based preprocessing.  
2. **Keyword Fusion:** Merges project-specific and domain-specific keywords for consistent metric evaluation.  
3. **Quantitative Scoring:**  
   - Raw and normalized frequency analysis  
   - TF-IDF weighted scoring  
   - Semantic embedding similarity using `SentenceTransformer`  
4. **Comparative Visualization:** Produces interpretable multi-metric visual analytics.  
5. **Simulation Modeling:** Emulates blockchain throughput, latency, and gas fee behavior across transaction scales.

## 📈 Insights

- **FarmBridge** demonstrates superior performance in **Accessibility**, **RBAC Quality**, and **User Experience** compared to reference systems.  
- Transaction **throughput stabilizes near 30–35 TPS**, maintaining low latency under high transaction loads.  
- **Gas cost** increases marginally, confirming cost-efficiency for scalable deployment.  
- The AI-driven multilingual accessibility and decentralized identity verification provide measurable improvements in inclusion and transparency.
